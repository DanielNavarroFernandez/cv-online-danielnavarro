# cv-online

Mi portfolio como desarrollador full-stack: **[cv-online-danielnavarro.vercel.app](https://cv-online-danielnavarro.vercel.app)**

- HTML, CSS y JavaScript sin frameworks, en un solo `index.html`.
- Versión en español e inglés; se abre en inglés si el navegador está en inglés.
- Esquema interactivo de la integración WooCommerce, Dolibarr y EspoCRM que hice en prácticas.
- Formulario de contacto con FormSubmit.
- Desplegado en Vercel desde la rama `main`.

| `index.html` | La web completa |
| `foto.jpg` | Foto de perfil |
